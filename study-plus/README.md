# WORD FRONTLINE STUDY PLUS

従来版とは別URLで公開する、ブラウザ完結型の英単語学習ゲームです。先生から提供されたExcelの全1,450語（Lesson 1〜68）、テスト範囲選択、学習継続日数、オリジナル・リスニングラボ、日→英出題を追加しています。

初回は端末の日付から、次に予定されているテスト範囲を自動選択します。たとえば6月24日〜9月2日は「第3回・夏休み課題」です。スタート画面の「今回のテスト範囲」から手動で切り替えると、その選択を維持します。「今日の日付に合わせる」で自動選択へ戻せます。範囲外の苦手データは削除しません。第1〜9回は一斉学習を数分〜約10分で一周できる規模です。1,450語の全範囲は約62分が目安のため、通常は第1〜9回に分けてください。

### 学習継続日数

- ページを開くだけでは加算しません。単語またはリスニングに1問答えた日を1日と数えます。
- 同じ日に何問答えても、継続日数は1回だけ増えます。
- 前日に学習していれば翌日に+1。2日以上空けて戻った場合は0日表示になり、次の1問で1日目から再開します。
- 7日続けるごとに「保険チケット」を1枚獲得します（最大2枚）。休んだあと次に1問答えたとき、休んだ日数分のチケットが自動で使われ、継続日数が守られます。足りない場合は0日に戻り、チケットは残ります。画面を開いただけではチケットは使われません。
- 端末の時計が一時的にずれて過去や未来の日付になっても、継続日数は消えません。
- 時間切れは「回答」として数えません（継続日数・今日の目標の対象外）。
- 21日を超えると「先生や保護者の方に自慢しよう！」と表示します。
- 日数は端末とブラウザごとに保存します。氏名や学校名は保存・送信しません。

### 続けたくなる仕組み（v4.2）

慣れて飽きることを防ぐため、`study-motivation.js` / `.css` で次の要素を追加しています。報酬はすべて見た目（称号・紋章・部隊カラー・戦場テーマ）だけで、出題や採点は変わりません。

| 要素 | 内容 |
|---|---|
| 階級 | 回答・ボス撃破・カード獲得などで「戦功」がたまり、二等兵〜元帥の19段階で昇進。昇進ごとに特別補給箱。 |
| 制覇マップ | 選択中の範囲の全単語を1語1マスで色分け（未出題・苦手・覚えかけ・制覇＝今3回以上連続で正解中・完全制覇＝5回以上連続で正解中）。間違えると「苦手」に戻ります。テスト日までの日数と1日あたりの必要ペースを表示。 |
| 補給箱 | 正解・苦手撃破・ボス撃破などでランダムに獲得。レア度4段階（コモン〜レジェンド）、全62種。前から苦手だった単語を倒すと強化補給箱が出やすく、14個連続でエピック未満なら次はエピック以上が確定。重複は戦功に変換。 |
| 単語カード図鑑 | ボス戦で倒すか3回連続正解でカード獲得、5回連続正解で金カード。40語以上のリストで、25/50/75/100%の達成報酬。以前の版で制覇済みの単語は、最初に開いたときにカードとして入ります。 |
| 今日の目標 | 銅＝1問、銀＝20問（リスニングの回答も1問ずつ数える）、金＝前から苦手だった単語を5語撃破（苦手が1語も残っていなければ50問に正解）。一度もらったメダルは消えません。 |
| 本日の作戦 | 日付で8種類が順番に変わる特別ステージ（動詞・名詞・形容詞副詞だけ、電撃戦、聴音＝英語を隠して音声のみ、弱点掃討、精鋭撃破、未知領域偵察）。正答率70%以上で1日1回、特別補給箱。英語音声が使えない・品詞情報がないなどで作戦のルールを使えないときは全単語で出題し、報酬は強化補給箱。日付をまたいだステージは対象外。 |
| 週間戦績カード | 直近7日間の学習日数・回答数・正答率・ボス撃破・制覇率などを1080×1350のPNGに描画。保存や共有をして、ロイロノートで提出可能。氏名は入りません。 |
| ゴースト戦 | 約7日前（同じ範囲・同じ遊び方を優先）の自分の正答率と平均回答時間を相手に、戦闘中に点差を表示。勝利報酬は1日3回まで。 |

報酬は「正しく答えた量」と「前から苦手だった単語に向き合った量」が中心です。

- 一斉学習・苦手一斉学習の完走報酬は初めて正解した数に比例し（20問で満額）、完走の補給箱はその正答率が50%以上のときだけ確定します。
- 不正解と時間切れは戦功0です。その回に間違えた単語を後で正解しても、苦手撃破・カード獲得・完走報酬の正解数にはなりません（わざと間違えても得をしない）。
- オンライン対戦は最後まで全員がつながった対戦だけが完走扱いで、補給箱の確定は単独1位のときだけです。
- 図鑑の達成報酬と、ボス完全撃破・完走・作戦の確定補給箱は40語以上のリストだけが対象です。自作リストは内容ごとに別々に記録します。
- ゲームを複数のタブで開いていても、ほかのタブで増えた記録を上書きしません。

### 日→英出題と「もう1回」の工夫（v4.3）

`study-boost.js` / `.css` で次の要素を追加しています。

| 要素 | 内容 |
|---|---|
| 出題形式 | 「作戦モード選択」画面（または設定）で **英→日**（従来どおり意味を選ぶ）／**日→英**（日本語の意味と品詞を見て英単語を選ぶ）／**ミックス**（1問ごとにランダム）を選択。通常・苦手・一斉学習・本日の作戦・苦手ボスで共通。日→英の初回正解は戦功+3。 |
| 日→英の安全策 | 回答前は英語の自動発音・再生ボタン・Spaceキー・戦場ゲートの意味表示を止め、回答後に正解の英単語を表示・発音。意味が近い単語、別の意味が問題文に当てはまる単語、つづりの似た同じ仲間（careful／carefully など）は選択肢に同時に出さない。問題文に答えの英単語が含まれる場合は「～」で隠す。全1,450語で安全な4択が作れることを確認済み。作れない単語があれば、その1問だけ英→日で出題。 |
| 例外 | 音声強化モードと聴音作戦は英→日。オンライン対戦はホストの出題形式を全員に送る（ミックスも1問ごとに全員同じ）。 |
| 回答後の答え合わせ | 4つの選択肢それぞれに、反対側（日→英なら意味、英→日なら英単語）を小さく表示。収まらない場合は省略。 |
| コンボと効果音 | 連続正解数を戦場に表示し、5・10・15・20・30…連続で演出。効果音はWeb Audioで合成（音声ファイルなし）。正解音はコンボが続くほど高くなる。🔊ボタンまたは設定でオフ。 |
| 自己ベスト | 最高コンボ、1日の最多回答数、平均回答時間の最速（20問以上・正答率80%以上）、日→英の正解数、累計正解数をスタート画面に表示。更新時に通知。 |
| 結果のふりかえり | 「新たに制覇した単語」「撃破した苦手」「今回ミスした単語（その後正解なら✓）」をタップで発音できる一覧で表示し、前回の正答率と比べたひとことを表示。 |
| NEXT GOALS | 銀・金メダル、次の階級、図鑑の達成報酬、範囲の全制覇、最高コンボのうち「達成に近い順」に3つを残り量つきで表示。 |
| 今日のおすすめ | スタート画面の「ゲーム開始」の隣に、苦手（3語以上で金メダル未達成）→未出題の単語→本日の作戦→通常モードの順で1つを提案し、1タップで出撃。 |

### 裏モード・リスニングラボ

スタート画面の `WORD FRONTLINE` ロゴを2.6秒以内に5回タップ、またはPCで `listen` とタイプすると開きます。直接 `listening.html` を開いても利用できます。

- 共通テスト対策: 前半は2回、後半は1回再生。短い対話から複数情報の統合まで。
- 英検準2級対策: 応答文選択、対話、短い説明。全問1回再生。
- 英検2級対策: 対話と社会的話題の説明。全問1回再生。

問題文・選択肢・解説はすべてこのサイト用に新規作成したオリジナルです。過去問本文、公式音声、図版、選択肢の転載や言い換えはしていません。ブラウザのWeb Speech APIで英語音声を合成するため無料です。

## 従来版との分離

新版と従来版はURL、公開フォルダ、ファイル、保存キーが別です。

```text
従来版: wordFrontlineSave_v1
新版ゲーム: wordFrontline:study-plus:game:v1
新版継続日数: wordFrontline:study-plus:streak:v1
新版の階級・補給箱・図鑑など: wordFrontline:study-plus:motivation:v1
新版の出題形式・効果音・自己ベスト: wordFrontline:study-plus:boost:v1
```

「記録リセット」では、継続日数と、階級・補給箱・図鑑・自己ベストなどの記録を、それぞれチェック欄で消すかどうか選べます（出題形式と効果音の設定は残ります）。

新版は従来版の保存キーを読み書き・削除しません。

## ファイル構成

- `word-frontline-study-plus.html`: ゲーム本体と基本エンジン
- `word-frontline-data.js`: Excelから変換した1,450語とテスト範囲プリセット
- `word-frontline-v2.js` / `.css`: 一斉学習、苦手ボス、2・3・4人対戦
- `word-frontline-plus.js` / `.css`: 範囲選択、新版固有の表示、裏モード入口
- `study-streak.js`: 単語とリスニング共通の継続日数と保険チケット、日ごとの回答数
- `study-motivation.js` / `.css`: 階級、制覇マップ、補給箱と装備、単語カード図鑑、今日の目標、本日の作戦、週間戦績カード、ゴースト戦
- `study-boost.js` / `.css`: 出題形式（英→日・日→英・ミックス）、コンボと効果音、自己ベスト、結果のふりかえりとNEXT GOALS、今日のおすすめ
- `listening.html` / `.js` / `.css`: 裏モード本体
- `listening-data.js`: オリジナル・リスニング問題
- `teacher-guide.html`: 授業用ガイド
- `peerjs.min.js` / `peerjs-LICENSE.txt`: 無料のWebRTC対戦用ライブラリとライセンス
- `.nojekyll`: GitHub Pagesの配信設定

## ブラウザだけで修正する

1. <https://github.com/takase20000307/word-frontline-random-boss/tree/main/study-plus> を開く。
2. 単語や範囲は `word-frontline-data.js`、リスニング問題は `listening-data.js`を開く。
3. 鉛筆アイコン、または <https://github.dev/takase20000307/word-frontline-random-boss/tree/main/study-plus> で編集する。
4. `Commit changes…` で保存し、GitHub Pagesの更新を数分待つ。

端末だけのカスタム単語は、ゲームの「単語リスト編集」でTSV/CSVを貼り付けて使えます。この操作は公開ファイルを変更しません。

## 費用と通信

GitHub Pages、Web Speech API、端末内保存を使うため、Firebaseや有料サーバーは不要です。通常学習とリスニングはオフラインでも動きます。オンライン対戦だけはPeerJS/WebRTCの通信を使います。
