# TRICK OR TREAT!

50分のハロウィーン授業。全員が各自のスマホで入室し、個人予想→班の相談→全員の最終回答に参加します。

- 練習2問＋本番24問。英語8問（L7 Section 1–2の語句から4問、単語アプリ第6回 Lesson 50–56から4問）。観察6・記憶4・ひらめき6。
- 先生が部屋を作り、参加リンクと6文字を配布。生徒はニックネーム・班を選ぶだけです。
- 教師のPCをホストにしたPeerJSデータ通信。データ接続APIは [PeerJS公式ドキュメント](https://peerjs.com/client/getting-started) に準拠。既存リポジトリの `../peerjs.min.js` とライセンスを利用します。
- 得点は正答率に比例（最大100）＋全員正解20点。練習は0点。最後の4問は2倍。未回答も分母に含みます。
- マシュマロの配布目安を、設定した合計個数に収まるよう整数で計算。結果はCSVで保存できます。
- タイマーの一時停止、手動進行、途中参加の受付、同じ端末の再接続、教師側のローカル保存・再開に対応。

使い方と出典は `guide.html`。`?demo=1` は通信なしの画面体験です。

## ローカル確認

リポジトリのルートをHTTPサーバーで配信し、`/halloween/` を開きます。JSモジュールのためfile://では起動しません。学校の実回線・実機で接続確認をしてください。ブラウザのWebRTCが禁止された環境では接続できません。

先生のタブが閉じられると授業の通信が止まります。先生と生徒の同じブラウザ・同じタブを保持してください。生徒画面には回答の正誤を発表まで配信しませんが、公開の教材用ソースには正解が含まれます。

## 教材出典

L7の語句は授業で扱った語句と照合済みです。単語アプリの実登録語・ID・出典行は各問題の `source` に保持しています。教科書本文や単語リスト全体は収録していません。
